# Betum Shop

[Betum Shop](https://lyone-k.github.io/betum-shop/) is an online storefront built with Next.js. Customers can browse [products], add items to a cart, and place orders from any device.

**Live site:** https://lyone-k.github.io/betum-shop/

## Features

- Product catalogue with [categories / search / filters]
- Shopping cart and checkout flow
- Responsive, mobile-first design
- [Order via WhatsApp / M-Pesa / payment provider]

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- React and TypeScript
- [Tailwind CSS / CSS Modules]
- Deployed on GitHub Pages

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/Lyone-K/betum-shop.git
cd betum-shop
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
app/          Pages and layouts
components/   Reusable UI components
public/       Images and static assets
```

## Build

```bash
npm run build
```
